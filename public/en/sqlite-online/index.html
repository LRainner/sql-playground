How SQLite Online works

SQL Playground uses SQLite WASM to run SQL without a server-side database. The editor can suggest tables, columns, and functions from the active SQLite runtime. Start with the demo database or import your own SQLite file.

  1. Open the playground in a modern browser.
  2. Run a query against the demo table or import a local database.
  3. Review the result and export it when you are done.

Try a SQLite query

The demo database contains membership records. This query groups them by plan and sorts the most popular plan first: 

SELECT plan, COUNT(*) AS members
FROM demo
GROUP BY plan
ORDER BY members DESC;

You can also create tables, insert rows, update data, and inspect the refreshed schema in the sidebar. Results can be exported as CSV when you need to continue working elsewhere.

Browser compatibility and limits

This workspace uses SQLite compiled to WebAssembly and works in current desktop browsers. It accepts local .db, .sqlite, and .sqlite3 files. The active database lives in the current browser tab: refreshing the page recreates the demo database, although your SQL query tabs are restored locally. Performance and maximum database size depend on the memory available to your browser.
