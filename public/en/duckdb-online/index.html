How DuckDB Online works

SQL Playground loads DuckDB-Wasm when you first select the DuckDB engine. The database session stays in the current browser tab, and the editor provides table, column, and function suggestions from the active engine.

  1. Open the DuckDB playground in a modern browser.
  2. Use the demo table or import a local data file.
  3. Run analytical SQL and export the result as CSV.

Try an analytical query

DuckDB is designed for analytical SQL. The demo table can be summarized by plan with a familiar aggregation: 

SELECT plan, COUNT(*) AS members
FROM demo
GROUP BY plan
ORDER BY members DESC;

When you import CSV, JSON, or Parquet, SQL Playground creates an imported table. A DuckDB database file is attached directly, so its existing tables become available from the schema browser.

Browser compatibility and limits

DuckDB-Wasm runs queries in a Web Worker and loads its compatible runtime from jsDelivr when the engine is selected. Imported files stay in the browser, but available memory and browser storage still limit practical dataset size. The current session supports .duckdb, CSV, JSON, and Parquet files and is recreated after a page refresh; saved SQL query tabs remain available.
