How PostgreSQL Online works

SQL Playground loads PGlite only after you select PostgreSQL. The database lives in the current browser tab, and imported SQL is executed locally. This playground does not connect to a remote PostgreSQL server.

  1. Open the PostgreSQL playground in a modern browser.
  2. Run the demo query or import a UTF-8 SQL file.
  3. Inspect the result and export it as CSV.

Try PostgreSQL syntax

PGlite supports PostgreSQL expressions and functions. This query converts the demo date values to calendar months and aggregates the rows: 

SELECT date_trunc('month', joined_at)::date AS month,
       COUNT(*) AS members
FROM demo
GROUP BY month
ORDER BY month;

Multiple SQL statements can run together, and the playground displays the last statement that returns rows. PostgreSQL arrays, JSON values, large integers, dates, and binary values are normalized for display and CSV export.

PGlite compatibility and limits

PGlite packages PostgreSQL as WebAssembly, so this tool does not connect to a remote PostgreSQL server. You can import UTF-8 .sql files up to 20 MB. Server-only features, external files, and psql meta-commands such as \copy and \connect are not supported. The database is recreated after a refresh, while your SQL query tabs remain saved in this browser.
