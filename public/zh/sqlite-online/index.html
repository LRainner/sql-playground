SQL Playground

在线运行 SQLite，数据默认留在本地。

直接在浏览器中执行 SQLite 查询。本地打开数据库文件、查看表结构并导出查询结果，你的数据不会离开当前设备。

打开 SQL Playground → 工作原理 English

完全本地运行

SQLite 编译为 WebAssembly，所有查询都在你的浏览器中执行。

数据库文件不上传

导入的 .db 文件仅在当前浏览器中打开，不会发送到服务器。

查询结果随时导出

查看表结构、编写 SQL，并将查询结果导出为 CSV 文件。

SQLite 在线工具如何工作

SQL Playground 使用 SQLite WASM 在没有服务端数据库的情况下执行 SQL。编辑器会根据当前数据库自动提示表名、字段名和函数。你可以使用示例数据库，也可以打开自己的 SQLite 文件。

  1. 在现代浏览器中打开 SQL Playground。
  2. 查询示例表，或者导入本地 SQLite 数据库。
  3. 查看查询结果，需要时导出为 CSV。
