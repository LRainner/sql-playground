SQLite 在线工具如何工作

SQL Playground 使用 SQLite WASM 在没有服务端数据库的情况下执行 SQL。编辑器会根据当前数据库自动提示表名、字段名和函数。你可以使用示例数据库，也可以打开自己的 SQLite 文件。

  1. 在现代浏览器中打开 SQL Playground。
  2. 查询示例表，或者导入本地 SQLite 数据库。
  3. 查看查询结果，需要时导出为 CSV。

试运行一条 SQLite 查询

示例数据库包含不同套餐的会员记录。下面的查询会按套餐分组，并把人数最多的套餐排在前面： 

SELECT plan, COUNT(*) AS members
FROM demo
GROUP BY plan
ORDER BY members DESC;

你也可以创建表、插入记录或修改数据，侧栏中的表结构会在查询成功后自动刷新。需要在其他工具中继续处理时，可以将结果导出为 CSV。

浏览器兼容性与限制

本工作区使用编译为 WebAssembly 的 SQLite，适用于当前主流桌面浏览器，支持本地打开 .db、.sqlite 和 .sqlite3 文件。数据库存在于当前浏览器标签页中，刷新页面会重新创建示例数据库，但已经编写的 SQL 查询标签会保存在本地。可处理的数据库大小取决于浏览器可用内存。
