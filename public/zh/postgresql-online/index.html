PostgreSQL 在线工具如何工作

只有选择 PostgreSQL 时，SQL Playground 才会加载 PGlite。数据库存在于当前浏览器标签页中，导入的 SQL 也完全在本地执行。本工具不会连接远程 PostgreSQL 服务。

  1. 在现代浏览器中打开 PostgreSQL Playground。
  2. 运行示例查询，或者导入 UTF-8 SQL 文件。
  3. 查看结果，并按需导出为 CSV。

试运行 PostgreSQL 语法

PGlite 支持 PostgreSQL 表达式和函数。下面的查询会把示例日期转换为月份并统计记录数量：

SELECT date_trunc('month', joined_at)::date AS month,
       COUNT(*) AS members
FROM demo
GROUP BY month
ORDER BY month;

你可以一次运行多条 SQL，界面会展示最后一条返回数据的语句。PostgreSQL 数组、JSON、大整数、日期和二进制结果会被转换为适合表格展示与 CSV 导出的形式。

PGlite 兼容性与限制

PGlite 将 PostgreSQL 打包为 WebAssembly，因此本工具不会连接远程 PostgreSQL 服务器。你可以导入不超过 20 MB 的 UTF-8 .sql 文件；服务端专用功能、外部文件，以及 \copy、\connect 等 psql 元命令不受支持。刷新页面会重建数据库，但 SQL 查询标签仍会保存在当前浏览器中。
