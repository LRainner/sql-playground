PostgreSQL 在线工具如何工作

只有选择 PostgreSQL 时，SQL Playground 才会加载 PGlite。数据库存在于当前浏览器标签页中，导入的 SQL 也完全在本地执行。本工具不会连接远程 PostgreSQL 服务。

  1. 在现代浏览器中打开 PostgreSQL Playground。
  2. 运行示例查询，或者导入 UTF-8 SQL 文件。
  3. 查看结果，并按需导出为 CSV。
